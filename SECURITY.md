# Security Policy

## Reporting a vulnerability

Report vulnerabilities through [GitHub private vulnerability reporting](https://github.com/wasely/watch-better/security/advisories/new).
Do not open a public issue for a suspected vulnerability.

Include the affected version, reproduction steps, expected impact, and any safe
supporting material. Remove cookies, tokens, account details, private transcripts,
and other personal data.

WatchBetter has no published long-term support schedule. Security fixes target the
current default branch and latest published build.
