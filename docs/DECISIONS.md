| DEC-011 | A tab- and provider-scoped session rule removes anti-frame headers only for verified ChatGPT/Gemini frames.                            | Supports embedded providers with the narrowest possible header exception.                                                           | Confirmed             |
| DEC-012 | Each provider frame returns a one-use panel session binding; `webNavigation` verifies it is a direct child before exact-frame routing. | Rejects stale, nested, cross-tab, cross-session, and wrong-provider prompt delivery.                                                | Confirmed             |
| DEC-013 | Message and provider allowlists reject unknown fields, unsupported hosts, and oversized prompts.                                       | Limits privileged routing and accidental data transfer.                                                                             | Confirmed             |
| DEC-014 | No analytics, Watch Better backend/account, remote code, broad host access, or semantic skipping.                                      | Keep repository and runtime surface narrow.                                                                                         | Confirmed             |
| DEC-015 | Ship one Chrome 133+ package for supported desktop Windows, macOS, Linux, and ChromeOS; do not claim mobile Chrome support.            | State-preserving `moveBefore()` requires Chrome 133; desktop packaging is OS-neutral and mobile Chrome does not install extensions. | Confirmed             |
| DEC-016 | Support desktop `/shorts/<videoId>` alongside `/watch?v=<videoId>` using a bounded right dock.                                         | Shorts `#details` variants can be page-wide; the dock keeps controls visible without altering the player or feed.                   | Confirmed             |
| DEC-017 | Prepare ChatGPT/Gemini frames and preload DeepSeek in an inactive tab as a supported YouTube page opens.                               | Avoid provider startup delay while preserving focus and keeping transcript/prompt transfer explicit.                                | Superseded by DEC-021 |
| DEC-018 | Resolve Short captions through matching active metadata, then the player endpoint, then watch-page metadata.                           | Shorts often omit caption data from the first page payload; ordered fallbacks improve coverage without inventing transcript.        | Confirmed             |
| DEC-019 | Detach the already-mounted runtime into a movable card inside the same YouTube tab, then create a fresh rail runtime.                  | Preserves the exact transcript/provider iframe and in-flight response while allowing continued browsing and multiple cards.         | Confirmed             |
| DEC-020 | Key embedded provider routing by top-level tab, provider, and frame session ID.                                                        | Multiple detached and rail sessions in one YouTube tab must never cross-route prompts or responses.                                 | Confirmed             |
| DEC-021 | Ship only providers that embed in the panel (ChatGPT, Gemini); remove DeepSeek and the automatic provider tab preload.                 | Watch Better must never open a browser tab or window on its own; DeepSeek could only ever work as a separate tab.                   | Confirmed             |
| DEC-022 | A detached card seeks only the video already open in the tab, and is inert otherwise; it never opens or navigates a tab.               | Timestamp clicks must not move the viewer off what they are watching.                                                               | Confirmed             |
| DEC-023 | The panel renders even when settings fail to load, after bounded retries fall back to defaults, and warns on the console.              | A rejected storage read used to hide the sidebar silently for the life of the tab.                                                  | Confirmed             |
